# タイプ別ショートカットとMarkdown編集

## 設定

［タイプ別設定 → ショートカット］でキー、Shift/Ctrl/Alt、機能を選んで［割り当て］を押します。

- ［割り当て解除］は、そのタイプでそのキーの機能を未割り当てにします。
- ［共通設定に戻す］は、タイプ別の上書きを取り消します。
- `*` は選択中の修飾キーの組み合わせに上書きがある印です。
- ［OK］で保存し、［キャンセル］で変更を破棄します。
- メニュー、ステータスバー、ツールチップ、ファンクションキー表示、［キー割り当て一覧をコピー］には現在のタイプの割り当てが反映されます。

Markdown用の機能は［編集系］から選べます。［コマンド一覧］からも実行できます。

## Markdownの初期割り当て

新規設定のMarkdownタイプは `md,markdown,mdown` を対象にします。
既存設定への初回追加では、すでにMarkdownという名前のタイプ、またはこれらの拡張子を扱うタイプがある場合は、その設定を維持します。
タイプ数が上限の場合も既存タイプを上書きしません。
追加済みのタイプを削除した場合、次回起動時に勝手に復元しません。

| キー | 機能 |
| --- | --- |
| Ctrl+B | 太字 |
| Ctrl+I | 斜体 |
| Ctrl+Shift+X | 取り消し線 |
| Ctrl+1～6 | 見出し1～6 |
| Ctrl+Shift+Q | 引用 |
| Ctrl+Shift+8 | 箇条書き |
| Ctrl+Shift+7 | 番号付きリスト |
| Ctrl+Shift+9 | タスクリスト |
| Ctrl+Enter | タスク完了／未完了の切り替え |
| Ctrl+E | インラインコード |
| Ctrl+Shift+C | コードブロック |
| Ctrl+K | リンク |
| Ctrl+Shift+K | 画像 |
| Ctrl+Shift+T | 表 |
| Ctrl+Shift+H | 水平線 |

これらもタイプ別設定で変更できます。ほかのタイプでは共通設定を継承します。

## 編集動作

- 太字・斜体・取り消し線：選択文字列を囲みます。通常選択では、選択した記号ごと、または中身を選択した状態から同じ機能で解除できます。未選択なら記号を挿入し、その間にカーソルを置きます。
- インラインコード：選択内のバッククォートより長い区切りを使い、必要に応じて内側に空白を入れます。
- 見出し：現在行または選択行の見出しレベルを変更します。同じレベルを再指定すると見出しを解除します。
- 引用・リスト：現在行または選択行に記号を付けます。全対象行が同じ種類なら解除し、リストの種類変更では既存のリスト記号を置き換えます。番号は1から順に振ります。
- タスク完了切り替え：全対象行が完了なら未完了に戻し、それ以外は完了にします。普通の行は完了タスクに変換します。
- コードブロック：現在行または選択行をフェンスで囲みます。内容中のバッククォートより長いフェンスを使います。生成されたフェンスを含む範囲を選択して再実行すると解除できます。
- リンク・画像：URL入力ダイアログを表示します。通常選択の内容をラベル／代替テキストに使い、未選択ならラベルを空にして、その位置へカーソルを置きます。URL入力をキャンセルすると文書は変更しません。
- 表：現在行または選択行のタブ区切りデータを表にします。先頭行をヘッダーにし、最低2列・データ1行を用意します。空行なら空の表を作ります。
- 水平線：現在行または選択範囲の内容を残し、その後ろに空行で区切った `---` を挿入します。
- 行単位の操作は折り返し表示ではなく論理行を対象にし、通常選択が次の行頭で終わる場合はその次の行を含めません。矩形選択では触れている論理行全体を対象にします。
- インライン操作の矩形選択は、既存の括弧補完と同じく各表示行を囲みます。
- 新しく入れる改行は文書の入力改行コードを使用します。各操作はUndoで取り消せます。

## 太字・斜体・取り消し線の表示

Markdownタイプ、または拡張子に `md` / `markdown` / `mdown` を登録したタイプでは、本文の強調部分を対応するフォントで表示します。

- `**太字**` / `__太字__`：太字
- `*斜体*` / `_斜体_`：斜体
- `***太字斜体***`、太字と斜体の入れ子：太字＋斜体
- `~~取り消し~~`：取り消し線。太字・斜体との併用にも対応します。

記法の記号はそのまま表示します。表示上の折り返しや段落内の改行をまたぐ強調にも対応します。
コードスパン、フェンスで囲んだコード、インデントしたコード行、リンクのURLは強調対象から除きます。
対応する開始／終了記号がない箇所やエスケープした記号、単語内の `_` を強調の開始・終了と誤認しないように判定します。
選択・検索時の文字色を保ったまま強調フォントを適用し、日本語等のフォールバックフォントにも太字・斜体・取り消し線を適用します。
取り消し線は本文中の空白・タブにも描画します。単独の `~` や3個以上連続する `~` は取り消し線として扱いません。
文字の配置幅は既存の編集用グリッドを使用します。

通常フォントがThin／Lightでも、強調部分には最低700（Bold）の太さを指定します。
フォント一覧の先頭を［変更］すると、通常表示用のスタイルとサイズも選択・保存できます。
フォント選択のスタイルが空欄の場合は通常の太さ・斜体なしを使用し、以前のスタイルを引き継ぎません。
Thin等の名前付きフェイスの通常の太さは、Windowsが列挙するフォント情報から取得します。

## 手動確認項目（確認手順）

以下は実施結果ではありません。

1. `.md` と `.txt` を開き、Ctrl+B／Ctrl+Iの動作とメニュー・キー一覧の表示が各タイプの設定に対応すること。
2. ［ショートカット］で未使用キーへの割り当て、明示的な解除、共通設定への復帰、OK／キャンセルを確認すること。修飾キー8通りも切り替えること。
3. F1～F12をタイプ別に変更し、修飾キーを押し直さなくてもタイプ変更後の表示とクリック時の機能が一致すること。
4. 設定保存・全終了・再起動で上書きと解除が保持されること。Markdownタイプ削除後に再追加されないこと。
5. 旧設定の独自タイプ（特にインデックス17）、既存Markdownタイプ、タイプ数上限を維持すること。
6. 全Markdownコマンドについて、空文書、未選択、通常選択、逆方向選択、矩形選択、複数行、日本語、折り返し行、末尾改行あり／なしで結果を確認すること。
7. 太字等の解除、見出しレベル変更、リスト相互変換、タスク完了切り替え、フェンス内のバッククォート、表中の `|` とタブ、URL中の空白・括弧を確認すること。
8. CRLF／LF、Undo／Redo、読み取り専用での編集禁止、URL入力のキャンセルを確認すること。
9. 日本語・英語・中国語で新しいタブと20個のMarkdownコマンド名を確認すること。
10. 太字・斜体・太字斜体、入れ子、日本語、画面外や折り返し前の開始記号、段落内の改行、コード内・エスケープした記号を確認すること。選択・検索中、分割ペイン、フォールバックフォント設定時も確認すること。
11. 開始／終了記号やコードフェンスを編集したとき、前後の行の表示も更新されること。Undo／Redo、タイプ変更後の表示も確認すること。
12. 通常フォントをThin／Lightにして、通常文字と太字の見た目が異なること。フォント一覧の先頭のスタイル変更・保存・再表示と、スタイル空欄からの通常表示への復帰を確認すること。
13. `~~取り消し~~`、`~~**太字**~~`、`~~*斜体*~~`、`~~***太字斜体***~~` の本文に取り消し線が表示され、区切り記号には付かないこと。空白・タブ、選択・検索色、フォールバックフォント、折り返し、Undo／Redo、コード内も確認すること。
