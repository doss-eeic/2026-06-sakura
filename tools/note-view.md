# ノート表示：本文の間に画像を表示する

`x64/Debug/sakura.exe` を起動し、「設定」→「ノート表示」で切り替える。初期状態はOFF。既存のメニュー設定に項目がない場合は、機能一覧の「設定」から「ノート表示」（機能コード **31105**）を追加できる。

```text
図の説明
![写真](C:/Pictures/photo.png)
続きの文章
```

ONにすると、単独行の画像リンクの直下に12行分の画像ブロックが入り、続く文章が下へ移動する。リンクの前後の空白・タブは許容される。文中リンクや複数リンクの行はブロック化しない。

- 対象は既存機能と同じ、ローカルドライブの絶対パスを持つPNG/JPEG。
- リンク文字列も本文もそのまま編集できる。画像の高さに相当する空行は保存されない。
- 「画像リンクを挿入...」や画像ドロップは、ON中だけ必要な改行を補ってリンクを単独行にする。補正した改行も一回のUndoに含まれる。
- 画像は横スクロールで動かず、縦スクロールでは途中まで表示できる。クリックするとリンク行先頭へ移る。
- 読込中は「読み込み中」、欠損・破損などは「画像を表示できません」。いずれも領域の高さは変わらない。
- ON中は文中を含むすべての画像ホバーが停止する。OFFに戻し、マウスを動かすと従来のホバーが使える。
- 表示状態はウィンドウ単位で、INIや本文には保存しない。分割ペインは同じON/OFF状態でスクロールは独立する。新しいウィンドウはOFF。
- ミニマップと印刷は従来どおりテキストのみを扱う。
- 外部で画像を更新した場合は、OFF→ONまたは本文の再読込で画像を読み直す。
